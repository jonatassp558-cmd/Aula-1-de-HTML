Neste paragrafo, veremos exemplos de tags de HTML:5 para analizarmos como funcionam.

A tag div, e um bloco retangular onde podemos colocar textos, figuras, etc. Dentro vamos colocar está tag que é tipo inline que não quebra linhas e não é tag de bloco.

Está tag section, é uma tag de bloco introduzida no HTML:5, considera-se uma semântica, tais como as tags article, section, header, fooder, figure... etc.
Na tag article, dentro colocaremos (strong), que deixa o texto em negrito, outro exemplo (i), que deixa seu testo em itálico, também podem ser usadar (u), que sublinha o texto e (mark) que deirará marcado.

Listas e listagem

Este proximo paragrafo vamos ver as tags de listagem e vamos demonstrar como funcionam. Para isso usaremos as tags (ul,li,ol) em demonstrações praticas. Começaremos com (ul>li*6), uma abreviação de HTML muito ultilizada no VS Code, isso cria uma lista não ordenada.

  • (ul)cria uma lista não ordenada.
  • (li)cria um item da lista.
  • (*6)significa a quantidade de repetição
  • Item
  • Item
  • Item

Outro exemplo que também podemos usar (ol>li*6) que cria uma lista ordenada para coisas importantes.

  1. item
  2. item
  3. item
  4. item
  5. item
  6. item
